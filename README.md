# Chicago City Data Analysis with SQL & Python

This project was completed as part of the **IBM Data Science Professional Certificate** on Coursera.  
It focuses on analyzing public datasets related to **Chicago’s crime, schools, and census data** using Python, Pandas, and SQLite.

---

## Project Overview
The goal of this project is to:
1. Load, clean, and integrate multiple real-world datasets (Census, Crime, and Public Schools of Chicago)
2. Store them in a local SQLite database (`FinalDB.db`)
3. Perform SQL queries to extract meaningful insights using **SQL Magic** in Jupyter Notebook

---

## Technologies Used
- Python (Pandas, SQLite3)
- Jupyter Notebook
- SQL (SQLite syntax)
- IBM Skills Network datasets (provided by Coursera)

---

## Datasets
All datasets were provided by **IBM Skills Network** for educational purposes.
